Speaker wake word

                        
Say this word to start a spoken reply (e.g. "Signer, I'd like a coffee"). The wake word is stripped from the transcript. Single word only.

                    

                    
                

            


            
            

                
Advanced


                

                    

                        
CTQI alert threshold

                        
Captions with CTQI below this value get a red pulsing border + optional chime. 0–100, default 80.

                    

                    
                


                

                    

                        
CTQI hard floor

                        
Captions with CTQI below this value are replaced with [unclear] instead of showing the constructed sentence (the model is essentially guessing). CTQI badge + Regenerate / Edit chips still appear so the signer can rescue the message. 0–100, default 40.
