================================================================================
                    SignBridge (asl-v1) — Project Structure
================================================================================

SignBridge is an end-to-end ASL-to-English translation system that captures
American Sign Language video, extracts skeletal pose landmarks, classifies
individual signs using transformer-based models, and assembles predicted
glosses into natural English sentences via an LLM pipeline.

The codebase spans data preparation, model training, inference APIs, and
multiple client applications (web, mobile, captioning).

================================================================================
  PIPELINE OVERVIEW (data flow)
================================================================================

  1. VIDEO CAPTURE        Camera/file → raw video frames
                          (applications/signbridge-app or mobile-asl-app)

  2. POSE EXTRACTION      Video → 576 MediaPipe keypoints per frame
                          (dataset-utilities/landmarks-extraction/)

  3. FEATURE ENGINEERING  576 keypoints → 279+ features
                          (83-point subset + finger features + spatial features)

  4. SEGMENTATION         Continuous pose stream → individual sign segments
                          (project-utilities/segmentation/)

  5. CLASSIFICATION       Each segment → top-k gloss predictions
                          (models/openhands-modernized/ transformer)

  6. SENTENCE ASSEMBLY    Ordered glosses → natural English via LLM
                          (project-utilities/llm_interface/)

  7. PRESENTATION         Captions displayed in real-time or burned onto video
                          (applications/signbridge-app, overlay_captions.py)
